# DeFi Toolkit

A modular DeFi utility library for interacting with Ethereum and EVM-compatible chains.

## Features
- Multi-chain support (Ethereum, Arbitrum, Optimism, Base)
- ERC20 token utilities
- Uniswap V3 pool reader and swap execution
- Aave V3 health factor monitor
- Portfolio tracker
- TVL and yield calculators
- Impermanent loss estimator
- Gas tracker
- Multicall3 batch RPC
- On-chain event listener

## Stack
- ethers.js v6
- CoinGecko API
- Multicall3
